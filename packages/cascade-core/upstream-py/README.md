# upstream-py — the verbatim-upstream build123d source flavors

Python sources for the two flavors that run **upstream build123d's own
code** instead of build123d-lite:

- **`pysrc=upstream`** (the MicroPython default): the vendored build123d
  release (`vendor/build123d-0.13.0/`, selected by `ACTIVE_UPSTREAM_VENDOR`
  in `src/worker/UpstreamB123d.js`) — Level-A builders/objects/operations,
  drafting, geometry.py and the whole topology package — runs on the custom
  micropython-cs interpreter, transformed at load by mechanical,
  line-preserving rewrites (`UpstreamB123d.js`), over the OCP-over-embind
  shim.
- **`pysrc=real`** (Pyodide, default-off): the unmodified PyPI wheel on
  CPython with real numpy, over the SAME shim (`src/worker/PyodideRealB123d.js`).

Layout:

- `ocp_shim/` — the OCP-over-embind shim. `_registry.py`, `table.json`,
  `OCP/*.py` and `MANIFEST.json` are GENERATED by
  `experiments/upstream-topology-spike/gen-ocp-shim.mjs` from the OCP bill
  (`extract_ocp_bill.py`, pybind signatures of the reference venv's OCP)
  and the fork's `cascadestudio.d.ts`; `OCP/collections.py` aliases OCP 8's
  `OCP.collections` names onto the embind typedef classes. Hand-written:
  `ocp_core.py` (MicroPython call layer), `ocp_core_pyodide.py` (Pyodide),
  `ocp_glue.py` (runtime-neutral stand-ins for classes the fork never bound),
  `topo_glue.py` / `real_glue.py` / `real_preglue.py` (worker glue: scene,
  measurement, export/import, text/gordon routing), `topo_bridge.py`,
  `numpy_micro.py`, `anytree.py`, `ipython_pretty.py`.
- `shims/` — stdlib/third-party shims MicroPython lacks (typing, enum with a
  real EnumMeta + StrEnum, dataclasses, contextlib, itertools, abc, inspect,
  ...; honest raising stubs for sympy/ocp_gordon/bd_materials). Registered
  via `sys.modules` aliasing (MicroPython builtins shadow `/lib`); order in
  `manifest.json`.
- `real-deps/` — import-satisfying stubs for the Pyodide leg's unbundled
  third-party deps (ezdxf, svgpathtools, ocpsvg, fontTools.ttLib, lib3mf,
  sklearn, requests, threejs_materials); each raises loudly on USE.
- `build123d/` — the package placeholder (`__init__.py`) and `_finalize.py`,
  which populates the namespace and installs the worker hooks on the
  MicroPython leg.
- `ocp_import_map.json` — every OCP name the vendored tree imports (inert
  stubs back any module the generated shim does not cover); regenerate with
  `experiments/upstream-topology-spike/gen_ocp_import_map.py`.

Bumping the vendored release: see
`experiments/upstream-on-micropython/BUMP-LEDGER-0.13.md` (the priced
recipe). Iterate in node with
`node experiments/upstream-topology-spike/topo-poc.mjs [script.py]` (real
OCCT wasm + MicroPython, no browser). Frozen contracts:
`test/py-src-upstream.spec.js`, `test/py-src-real.spec.js`.
